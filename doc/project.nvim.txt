1. project.nvim                                    *project.nvim-project.nvim*

**project.nvim** is a Neovim plugin that provides project management.


REQUIREMENTS                          *project.nvim-project.nvim-requirements*

- Neovim >= 0.11.0


FEATURES                                  *project.nvim-project.nvim-features*

- Automatically persist "projects" (cwd’s)
- Manage (add/delete) "projects"


INSTALLATION                          *project.nvim-project.nvim-installation*

Install the plugin with your favorite package manager:


VIM.PACK ~

>lua
    vim.pack.add({'https://github.com/TheLeoP/project.nvim'})
<


VIM-PLUG ~

>vim
    Plug 'TheLeoP/project.nvim'
<


API                                            *project.nvim-project.nvim-api*

Get a list of recent projects:

>lua
    require("project").get_recent()
<

Add a project

>lua
    require("project").add()
<

Delete a project

>lua
    require("project").delete()
<
